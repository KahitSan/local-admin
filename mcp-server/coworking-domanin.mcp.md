# KahitSan Coworking Space Domain Knowledge

## Business Context
- 24/7 coworking space with smart access locks
- Multiple space types: Entrance, Inner, Call Booth, Whole Area
- 8-hour session blocks with extension pricing
- No reservations needed - first come, first served

## Space Types & Pricing
- **Entrance Sector**: ₱99/8hrs, ₱15/hr extension, ₱99/8hr discount blocks
- **Inner Sector**: ₱149/8hrs, ₱15/hr extension, ₱120/8hr discount blocks  
- **Call Chamber**: ₱250/5hrs, ₱50/hr extension
- **Whole Inner Sector**: ₱500/2hrs, ₱250/hr extension

## Client Lifecycle
1. **Editing** - Setting up session details
2. **Active** - Currently using space with countdown timer
3. **Completed** - Session finished

## Key Features
- Smart access lock with auto-lock timer
- Real-time seat map visualization
- 6-digit access code generation
- Server monitoring (CPU, memory, temperature)
- Calendar booking visualization
- Payment tracking with balance calculation

## Terminology
- "Session" not "booking"
- "Access Code" not "password"
- "Sector" not "area" in UI labels
- "Chamber" for call booths
- Use "Initialize", "Protocol", "Matrix" for tech feel
